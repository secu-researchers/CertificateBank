# 생성 규칙

시험지 생성의 절차, 출제 원칙, 자가검증 루프를 정한다. 유형 어휘와 문항 서식은 `문제 유형.md`를 따른다.

## 1. 입력

선택한 자격증 SKILL, 유형별 문항 수, 난이도 분포, 주제 범위(선택), 배점(선택).

## 2. 생성 절차

1. **목표 설정**: 입력을 읽고 한 개의 목표(요청 조건을 만족하는 시험지)를 정한다. 입력이 모호하거나 자격증 SKILL의 출제 범위를 벗어나면 임의로 진행하지 않는다.
2. **분할**: 문항을 유형별·배치별로 나눈다. 한 배치는 최대 10문항이다. 한 번에 긴 출력을 만들지 않는다.
3. **배치 생성**: 배치마다 `3. 출제 원칙`으로 생성한다.
4. **자가검증**: 배치마다 4절의 검증 루프를 통과시킨다. 통과하지 못한 배치는 다음 단계로 넘기지 않는다.
5. **조립**: 모든 배치가 통과하면 문항 번호를 1부터 순차 재부여하고 시험지를 확정한다.

## 3. 출제 원칙

1. 자격증 SKILL의 출제 범위, 질문 카테고리, 문제 본문 구조를 따른다. 범위 밖 주제는 출제하지 않는다.
2. 문항 하나는 하나의 주제를 다루고, 질문만으로 정답이 하나로 도출되어야 한다. 정답과 채점 기준은 문항에 기재하지 않는다.
3. 사지선다형은 오답 보기가 그럴듯하되 명백히 틀려야 하며 정답은 정확히 하나다. 정답 위치를 한쪽으로 치우치지 않게 분산한다.
4. 보기 사용: 사지선다형과 보기형 빈칸은 필수, 나머지는 생략 가능. 생략하면 `options` 필드를 두지 않는다.
5. 난이도는 `문제 유형.md`의 상/중/하 기준에 맞추고 요청 분포를 따른다.
6. 실습형 문항의 코드·설정·로그 예시는 공개된 사실에 기반해 재구성한다. 실행 가능한 악성 페이로드는 넣지 않는다.
7. 사실 여부에 확신이 없는 내용은 출제하지 않는다. 불확실하면 그 문항을 폐기하고 다른 문항으로 대체한다.
8. 문항 수가 5개 이상이면 자격증 SKILL의 질문 카테고리를 각각 한 번 이상 포함한다. 문항 간 주제 중복을 피한다.
9. 모든 문항과 해설은 한국어로 쓴다. 전문 용어·명령어·코드는 표준 표기를 유지한다.
10. 장식적 표현을 쓰지 않는다. 사실·구조 정보만 담는다.
11. 출력은 `문제 유형.md`의 JSON 서식만 허용한다. 서식 밖 평문을 섞지 않는다.

## 4. 자가검증 루프

검증은 생성과 별도의 LLM 호출로 수행하며, 최대 2회까지 검증→개선을 반복한다.

### 4.1 검증 항목

**필터 A (문항 단위 완결성)**

1. 서식: JSON 스키마, 유형별 필수 필드, 보기 사용 규칙, 정답·채점 기준 미기재.
2. 정답 도출성: 검증자가 문항을 독립적으로 풀어 정답이 하나로 도출되는지 확인한다. 사지선다형·TrueFalse는 복수 정답이나 모호한 표현이 없는지, 서술류는 요구하는 답의 범위가 질문만으로 명확한지 확인한다.
3. 사실·논리 오류: 질문과 보기에 사실 오류나 모순이 없는가.
4. 핵심 요소: 질문이 답을 요구하는 바가 명확하고 문항 유형과 일치하는가.
5. 난이도: 표시된 난이도가 실제 풀이 복잡도와 맞는가.

**필터 B (시험지 단위 정렬성)**

1. 자격증 SKILL의 출제 범위와 카테고리에 부합하는가.
2. 요청한 유형별 문항 수·난이도 분포·주제 범위를 만족하는가.
3. 문항 간 중복이나 사소한 세부에 치우친 문항이 없는가. 있으면 "전략적 정렬 부족"으로 반려한다.

### 4.2 절차

1. 검증자는 문항별로 `통과` 또는 결함 목록을 반환한다. 결함은 위 항목 번호와 구체적 사유를 포함한다.
2. 결함 문항만 결함 목록을 반영해 다시 생성한다. 통과한 문항은 건드리지 않는다.
3. 재생성된 문항을 다시 검증한다. 이를 최대 2회 반복한다.
4. 2회 후에도 통과하지 못한 문항은 시험지에 포함하지 않고 폐기한다. 폐기로 문항 수가 모자라면 사용자에게 사유와 함께 통보한다.
5. 통과로 위장하거나 결함을 숨기지 않는다. 같은 결함의 무한 반복, 요청에서의 이탈, 성공 허위 보고, 서식 이탈을 실패로 간주해 즉시 중단하고 현재 상태를 통보한다.

### 4.3 기록

시험지 JSON에 검증 기록(회차별 문항 번호, 결함 항목, 조치)을 함께 저장한다. 화면에서 확인할 수 있어야 한다.

## 5. 자격증 SKILL 필수 항목

새 자격증 SKILL은 다음을 포함해야 한다.

1. 개요와 시험 형식
2. 출제 범위(주제 목록)와 범위 밖 처리 방침
3. 질문 카테고리와 카테고리별 문항 유형 매핑
4. 문제 본문 구조(예: 상황 설명 → 코드/구성 → 질문)
5. 자격증 고유 규칙과 표기 규칙
